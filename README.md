# FVSYOU!

Landing page for FVSYOU!, a free marketplace for HBCU students to trade with each other, launching first at Fort Valley State. Independent student project, not affiliated with FVSU.

Live at https://kiwenlol.github.io/yard-market/ (GitHub Pages, `main` branch, root).

To collect waitlist sign-ups, set `FORM_ENDPOINT` in `index.html` to a Formspree (or similar) form URL.

Pledge bar: edit `PLEDGED`, `GOAL` and `PLEDGE_URL` near the bottom of `index.html`.
Photos: add your own images as `images/photo-1.jpg` ... `photo-5.jpg`.
